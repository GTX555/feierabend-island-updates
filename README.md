# Feierabend Island

Eine kompakte Windows-App für die Feierabend-Prognose und ein lokales Lernjournal.

## Download

Unter **Releases** den aktuellen **Feierabend-Island-Setup-…-x64.exe** herunterladen und starten. Die App wird für das eigene Windows-Konto installiert. Ein eigenes BBC-Extranet-Konto wird für das Lesen der Arbeitszeiten benötigt.

## Updates

Ab Version 0.12 sucht die App beim Start nach einer neueren veröffentlichten Version. Dann erscheint links neben Verschieben und Profilbild ein weißer Download-Button. Ein Klick lädt den Installer, prüft Größe und SHA-256 und zeigt die Datei im Download-Ordner. Die Installation startet man selbst. Ein Klick auf die Versionsnummer unten prüft erneut.

Dieses Repository enthält die öffentlichen Download-Dateien. Persönliche Arbeitszeiten, Journalnotizen, Anmeldesitzungen und Zugangsdaten werden hier nicht veröffentlicht.

## Lokale Daten

Einstellungen und verschlüsselte lokale Daten bleiben bei einem Update erhalten. Die Extranet-Anbindung liest ausschließlich die vorgesehenen Daten; Arbeitsbuchungen und Profile werden nicht bearbeitet.
